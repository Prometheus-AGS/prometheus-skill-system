# change-rah-001-compile-baseline-and-timestamps

**Title:** Establish the compile baseline for both substrate crates and replace the fabricated timestamps in prometheus-research
**Repository:** `prometheus-skill-pack`
**Phase:** research-agent-hardening
**Goal:** G1
**Depends on:** none
**Backend:** native-kbd

## Why

Assessment BUILD HEALTH is UNKNOWN: `cargo check` on `prometheus-research` and `learner-model` was blocked four times by an external build. Every Rust adopt verdict in analysis (D-10, D-12, cand-006) is conditional on it. Independently, `checkpoint.rs:60` formats every timestamp as `1970-01-01T00:00:{secs%60}Z`, `mcp_server/mod.rs:186` hand-rolls a broken date, and `spawn.rs` hardcodes `2026-07-08T00:00:00Z` (G1, D-12).

## What Changes

- Run `cargo check -p prometheus-research` and `cargo check -p learner-model` once the machine is idle and record the result; if either fails, repair compile errors in this change before anything else.
- Adopt `chrono = { version = "0.4", features = ["serde"] }` in `prometheus-research`, the same pin `learner-model` uses; delete both hand-rolled formatters and the hardcoded literal; every checkpoint timestamp is RFC 3339 UTC from `chrono::Utc::now()`.
- Extend the existing integration test `tests/job_lifecycle.rs` so a job started through the production `start` path yields `started_at` and `last_updated_at` that parse as RFC 3339 and fall within 60 seconds of the test's own clock.

## ADDED Requirements

### Requirement: Checkpoint timestamps are real
WHEN a job checkpoint is written, THEN `started_at` and `last_updated_at` are RFC 3339 UTC timestamps within 60 seconds of wall-clock time.

#### Scenario: Job start
- **WHEN** a job is created through the `start` command or `research_start` tool
- **THEN** its checkpoint.json timestamps parse with `chrono::DateTime::parse_from_rfc3339` and are not in 1970

### Requirement: Compile baseline is recorded
The change SHALL record the `cargo check` result for both crates in `verification.md` before any dependency is added.

#### Scenario: Baseline
- **WHEN** `pgrep -x cargo` is empty
- **THEN** `cargo check -p prometheus-research` and `cargo check -p learner-model` both exit 0 and the outputs are pasted into Evidence
