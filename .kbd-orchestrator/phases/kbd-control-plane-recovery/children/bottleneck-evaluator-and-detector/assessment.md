# Assessment — bottleneck-evaluator-and-detector

The KBD runtime is already the signed authority, but lifecycle scripts and
harness hooks can bypass or lag its projections. The active parent reproduced
this: `plan.md` contained four changes while runtime revision 32 contained none.

The repair must be a lightweight controller, not an LLM at every boundary.
Deterministic evaluation owns normal progress and projection reconciliation;
cross-model review is reserved for terminal or ambiguous state. Operator Stop
remains unconditional and advisory hooks may never reinterpret it.

Build/test policy cannot be proven by parsing shell history because repository
rules prohibit command parsers and PreToolUse guards. Typed gate execution must
therefore create signed start/finish receipts, while missing receipts prevent
certification without pretending every direct historical command was observed.
