# Goals

- Map every extension point Kimi Desktop actually exposes, separating verified capability from vendor marketing and from CLI-only features
- Determine which extension points the prometheus-skill-pack should adopt, with an explicit rationale for each rejection
- Establish whether UI/UX customization of Kimi Desktop is achievable at all, and if not, record why so it is not re-investigated
- Keep every adopted integration reinstall-durable and free of app-managed-state traps
