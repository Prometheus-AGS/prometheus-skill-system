# AG-UI / A2UI / MCP App UI Frameworks

## Summary

Research into Agent-User interaction protocols, generative UI specifications, and MCP App design patterns for the Prometheus Deep-Research Skill.

## Key Findings

- **AG-UI**: Streaming protocol for real-time agent updates. Server-Sent Events (SSE) with structured delta formats.
- **A2UI**: Generative UI specification. Agents generate UI components dynamically based on context and user intent.
- **MCP App**: Embedded UI within the Model Context Protocol. Tools can expose their own UI surfaces.
- **Pattern convergence**: All three approaches solve the same problem — how to show agent progress and results without overwhelming the user.
- **Recommendation for Prometheus**: Support all three modes:
  - AG-UI for streaming progress during research
  - A2UI for generative artifact displays (charts, graphs, timelines)
  - MCP App for embedded configuration and result browsing
