# Codex skill catalog manifest
#
# Codex (0.144.x) renders every discoverable skill into a single "## Skills"
# section with a FIXED size budget (about 29.6K characters). Names and paths are
# mandatory; descriptions get whatever budget is left over. So each extra entry
# steals description text from every other entry:
#
#   ~130 entries -> ~166 char descriptions  (full, model triggers reliably)
#   ~200 entries ->  ~66 char descriptions  (usable)
#   ~360 entries ->  ~10 char descriptions  (useless -- model cannot tell skills apart)
#
# Codex does not de-duplicate: every SKILL.md it finds under every skill root is
# an entry, so one skill installed as a real copy, a prometheus-* alias, a
# symlink, a plugin-cache copy and a committed repo copy costs five entries.
#
# This file selects which PACK skills Codex may AUTO-TRIGGER. The selection is
# applied by shared/scripts/codex-catalog-config.sh, which writes a managed block
# of `[[skills.config]] enabled = false` entries into ~/.codex/config.toml. Nothing
# on disk is deleted or edited, so the signed generation stays intact. The same
# helper also disables redundant duplicate copies of a skill (pack or not) so each
# skill appears once.
#
# Excluding a skill here does NOT make it unavailable: scripts/register-slash-commands.sh
# registers a slash command for EVERY skill in the repo, pointing at the SKILL.md in
# this repo, and the helper refuses to exclude a skill that has no prompt. Slash-command
# prompts live outside the catalog budget, so an excluded skill is still invokable as
# /<skill-name> -- it just won't be auto-suggested.
#
# Only top-level skills are listed. A bundle's nested skills (for example the
# stage-* skills of deep-research) are internal steps of their bundle and are
# never auto-discoverable on their own.
#
# Syntax: one glob per line, matched against the repo-relative skill directory.
#   include <glob>    (default when no verb is given)
#   exclude <glob>
# Later rules win. Comments start with '#'.
#
# Verify the effect after editing:
#   bash shared/scripts/codex-catalog-config.sh --check
#   codex debug prompt-input | python3 scripts/codex-catalog-stat.py

# Start from nothing and opt in, so a new skill never silently grows the catalog.
exclude skills/**

# ---------------------------------------------------------------------------
# Third-party skills (anything that is not a pack skill). The catalog budget
# cannot hold the ~580 distinct third-party skills a developer machine collects
# (ECC alone is ~280), so Codex auto-discovers only the sources kept below.
# Skills that are excluded stay installed and keep working in every other tool;
# they are only hidden from Codex. Directives (applied by codex-catalog-config.sh):
#   third-party keep|exclude   what to do with third-party skills not matched below
#   keep-path <glob>           keep skills whose resolved path matches (~ expands)
#   keep-name <glob>           keep skills whose name matches
# ---------------------------------------------------------------------------
third-party exclude
keep-path ~/.codex/skills/.system/**
keep-path ~/.codex/plugins/cache/openai-*/**
keep-name openspec-*
