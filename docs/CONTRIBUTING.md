# Contributor reference

The maintained contributor workflow is [CONTRIBUTING.md](../CONTRIBUTING.md). Use its production-first phase boundary, local integration requirements, protected BDD approval and dependency ownership rules.

For skill structure and frontmatter, use [the skill template](SKILL_TEMPLATE.md) and [skill authoring](skill-authoring-guide.md). For package ownership and generated conflict handling, use [generated output ownership](generated-output-ownership.md). Do not merge generated payloads by hand or regenerate them against incomplete phase production.
