# Quick start

Follow the canonical [quick-start chapter](guide/00-quick-start.md) for source setup, selecting a skills-only target and starting a learning session. The root package requires Node.js 20.19.0 or later; team helpers require Node 22 or later. A skills-only installation does not require Forge or native service installation.

Use [installation](guide/19-installation.md) for `skills` and `full` profiles, supported platforms and custom Codex homes. Use [service operations](guide/26-service-operations.md) for independently configured services and their data. A successful install or health check does not establish harness invocation or release acceptance.

The former sync features are relocated to Companion. This pack does not install its daemon or certify pairing. [Deployment modes](deployment-modes.md) explains the boundary.
