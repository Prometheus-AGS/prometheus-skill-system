# UI/UX routing research and implementation record
Status: source research and approved architecture. Runtime and platform claims require separately recorded execution evidence.

The attachment is design input, not authority to bypass invocation restrictions. No evidence establishes a universally best UI skill. Selection rests on maintained vendor/author sources, relevant coverage, local architecture fit, traceable licensing and portable runtime closure.

The approved architecture separates one shared protocol from bundled skills and native team adapters. Project context remains authoritative; direction is limited to new work/redesign; Pro Max supplies domain/stack intelligence; craft and platform guides are selected narrowly. Native Impeccable engine parity is deferred in mini.

## Evidence
- [Impeccable](https://github.com/pbakaus/impeccable/tree/9d715cc4f5564a990ca8345abfdd5df6dc9b41c8): native engine dependency; portable context adaptation is explicitly narrower.
- [Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill/tree/dcc40ff5133ef78276117db0cc34e7b83cc8aeba): bundled CSV/search/reasoning/design persistence; TypeScript port must be checked against pinned reference cases.
- [Taste](https://github.com/Leonxlnx/taste-skill/tree/c184364c58658b2f131b4ae8bd3d206cabb3deee): preserve identities and experimental versions; use GPT-specific guidance by model family.
- [Jakub's skills](https://github.com/jakubkrehel/skills/tree/267330e1adfc66a718fb65fa6918c1f06d0a689e): seven craft skills plus user-only workflows. Automatic review uses a dedicated Prometheus skill.
- [Claude skill invocation](https://code.claude.com/docs/en/skills): disable-model-invocation is preserved, including preload restrictions.
- [Codex subagents](https://developers.openai.com/codex/subagents): native custom-agent config is separate from general team orchestration.
- [Zed instructions](https://zed.dev/docs/ai/instructions) and [parallel agents](https://zed.dev/docs/ai/parallel-agents): effective instruction precedence and ACP configuration differ; UI parallel threads do not establish a delegation API.
- [WCAG target size](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html): 24 CSS pixels with specified exceptions, not an unconditional universal touch minimum.
- Vendor platform selections and pinned asset hashes are in the catalog lock: Vercel, Expo, Flutter, SwiftUI and Android.
