## Why
Users need help choosing an agent team and carrying work between coding harnesses. Existing skills lack a shared, inspectable team definition and durable handoff workflow.

## What Changes
- Four skills: agent-team-creator, agent-team-manage, agent-team-models, agent-team-handoff.
- Guided task assessment, minimal role recommendations, durable task state, model capability/cost policy and portable handoffs.
- Native exports for UAR, Codex, Claude Code, Copilot, Kimi Code, MiniMax CLI, OpenCode and DeepSeek Harness.
- Shared Node.js runtime authored in TypeScript 7; optional memory bridges; plugins and both documentation sites.

## Capabilities
### New Capabilities
- `agent-team-management`: guided creation, native exports, model policy, task ownership and handoffs.
### Modified Capabilities
None.

## Impact
Only the full and mini skill packages in isolated codex/agent-team-creator branches. No host installation or changes to other product codebases.

## Prerequisite
Complete kbd-consistency-before-agent-teams before implementation. Prior draft artifacts have been reconsidered against the recorded Assess/Analyze outputs.
