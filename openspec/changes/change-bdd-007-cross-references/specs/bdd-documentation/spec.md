## ADDED Requirements

### Requirement: Cross-reference existing BDD rules

The new BDD skills SHALL link BDD-005, BDD-006, and BDD-007. The project instructions SHALL point at the lifecycle skill for immutable-test guidance, and the status matrix SHALL cover BDD-001 through BDD-015.

#### Scenario: Find the authoritative rules

- **GIVEN** a reader investigates an immutable feature or step file
- **WHEN** they follow the project instructions or a new skill's references
- **THEN** they reach the lifecycle rule and can look up the status of the related evolution items
