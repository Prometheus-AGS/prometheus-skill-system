## ADDED Requirements

### Requirement: Exercise minimum scenarios for BDD skills

The Cucumber JS, Cucumber Rust, lifecycle, and video-proof skills SHALL each include a minimal smoke entry point and meet strict skill validation.

#### Scenario: Validate the distributed BDD skill set

- **GIVEN** the four skills and their prerequisites are installed
- **WHEN** the maintainer runs their strict validation and smoke entry points
- **THEN** one complete scenario executes in each Cucumber implementation, both lifecycle guards are exercised, and the proof smoke test mints a bundle
