## ADDED Requirements

### Requirement: Distribute Cowork management documentation

The pack SHALL publish a cowork-management skill with its command reference, list it in the Claude marketplace, and expose Cowork in the project’s essential commands.

#### Scenario: Discover the command reference from the installed catalog

- **GIVEN** an operator browses the Claude marketplace for Cowork management
- **WHEN** they open the skill
- **THEN** they can reach the full command reference and find the linked commands from the project instructions
