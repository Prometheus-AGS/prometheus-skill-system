## ADDED Requirements

### Requirement: Explain contribution and deployment paths

Contribution documentation SHALL cover setup, skill development, validation, and review, and provide issue templates for bugs, features, and skills. Deployment documentation SHALL compare modes 0 through 3.

#### Scenario: Find a contribution path and deployment requirements

- **WHEN** a reader opens the contributor guide and deployment matrix
- **THEN** they can submit a structured issue or skill proposal and identify features available from CLI-only through peer sync
