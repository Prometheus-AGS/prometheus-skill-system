## ADDED Requirements

### Requirement: Serve one canonical guide source

The site SHALL serve docs/guide as the guide source and keep mappings from major README and CLAUDE.md sections to site pages or documented exclusions.

#### Scenario: Navigate to a canonical guide page

- **WHEN** a reader follows the README site entry point
- **THEN** the site renders the page from docs/guide, while the mappings identify the canonical sources and excluded operational instructions
