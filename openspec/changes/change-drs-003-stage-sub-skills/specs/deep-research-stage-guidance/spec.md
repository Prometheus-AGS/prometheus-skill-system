## ADDED Requirements

### Requirement: Describe the contract of each research stage

All ten research stages SHALL have a valid sub-skill with purpose, typed input, typed output, execution instructions, integration, and an example.

#### Scenario: Open the source verification stage

- **WHEN** an agent receives a batch to verify
- **THEN** its stage skill identifies the input fields, credibility result, integration, and example from which the workflow can be carried out
