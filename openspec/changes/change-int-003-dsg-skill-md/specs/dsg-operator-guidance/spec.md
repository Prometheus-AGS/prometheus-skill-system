## ADDED Requirements

### Requirement: Provide DSG guidance with safety references

The Disk Space Guardian skill SHALL explain quick start, safety, ecosystem detection, activity verification, retention, automation, knowledge logging, and troubleshooting. Detailed safety and ecosystem conventions SHALL have separate references.

#### Scenario: Choose cleanup for an active project

- **WHEN** an agent receives a disk cleanup request
- **THEN** the skill points it to activity and retention checks and the ecosystem reference before an applicable DSG invocation
