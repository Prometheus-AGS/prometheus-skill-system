## ADDED Requirements

### Requirement: Identify the Cowork 0.2.0 release

Cowork SHALL align the cli manifest and lockfile package version at 0.2.0, and publish the corresponding annotated source tag for release packaging.

#### Scenario: Resolve the Cowork release by tag

- **WHEN** an installer resolves v0.2.0
- **THEN** the tag identifies the source tree whose manifest and lockfile agree on 0.2.0
