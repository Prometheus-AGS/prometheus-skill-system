## ADDED Requirements

### Requirement: A missing local journal never silently forks a shared plan
The CLI SHALL NOT sign a new genesis event when the local journal is empty and the checked-in
`current-waypoint.json` was generated by `kbd-runtime` at a revision above 0, unless the operator
sets `PROMETHEUS_KBD_NEW_JOURNAL=1`.

#### Scenario: Teammate without the journal is refused
- **WHEN** a teammate whose machine has no copy of the project's journal runs a KBD write in a
  checkout whose waypoint records `generatedBy: "kbd-runtime"` and `sourceRevision: 3`
- **THEN** the command fails, names the project, run and revision, says how to sync or restore
  the journal, and no local journal is created

#### Scenario: Deliberate new journal
- **WHEN** the same command runs with `PROMETHEUS_KBD_NEW_JOURNAL=1`
- **THEN** a new journal is initialized as before

#### Scenario: New and legacy projects still bootstrap
- **WHEN** the waypoint is absent or has no `generatedBy: "kbd-runtime"`
- **THEN** the first KBD write initializes the journal as before
