# Agent context

Project instruction files, task state and selectively loaded skills provide different kinds of context. Keep project policy in its actual canonical source, route specialized guidance by task, and recover position through canonical KBD identity and revision. A shorter resident file is not automatically a better one.

The full context bootstrap has legacy and v4 layouts. Legacy uses managed `AGENTS.md` regions with a `CLAUDE.md` link or import; v4 renders `CLAUDE.md` and linked entrypoints from `rules/src/`. Existing authored prose, project UI protocol and selected teams have their own preservation rules. This repository's `CLAUDE.md` remains its canonical whole-stack policy; the bootstrap examples do not redefine it.

Start with [Quick Start](./quick-start), then [Harness Support](./harness-support), [Model Profiles](./model-profiles) and [Skill Budget](./skill-budget). The current [UI routing guide](/docs/guide/ui-ux-routing) and [team handbook](/docs/guide/agent-teams) describe project adoption and native delegation limits.
