# Quick Start

## Install

```bash
git clone https://github.com/prometheusags/prometheus-skill-pack
cd prometheus-skill-pack
bash scripts/install-skills-flat.sh
```

## Try a skill

In Claude Code:

```
/learn-goal "I want to understand Rust lifetimes"
```

## Check sync status

```
/sync-status
```

## Start the KBD lifecycle

```
/kbd-assess my-project
/kbd-analyze my-project
/kbd-plan my-project
/kbd-execute my-project
/kbd-reflect my-project
```
