# /learn-survey

Diagnose prior knowledge for an existing goal and its corpus:

```text
/learn-survey rust-basics
```

The skill builds eleven diagnostic items: five conceptual, three procedural and three misconception checks. Responses inform prerequisite gaps and a recursion floor for [learn-plan](/docs/learn/skills/learn-plan). Review that placement with the learner; question scores and self-report are evidence to inspect, not proof that every prerequisite is mastered.
