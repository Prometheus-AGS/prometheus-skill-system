# Platform: Codex CLI

**Detection:** `$TOOL == "codex"` OR `codex` binary in PATH and `$TOOL` not set to another tool.

Codex CLI uses the "Ralph Loop" (`/goal` command, v0.128.0+). KBD provides the
supporting prompt files and context injection — it does not reimplement the loop.

## Setup (one-time, per machine)

Run the Codex bridge setup script:
```bash
scripts/kbd-goal-codex-setup.sh
```

This:
1. Sets `goals.enabled = true` in `~/.codex/config.toml`
2. Copies KBD's `continuation.md` and `budget_limit.md` templates to `~/.codex/goals/`
3. Verifies `codex --version` ≥ 0.128.0

## Per-Goal Context Injection

Codex doesn't support `SKILL.md` — context reaches it via `AGENTS.md`. To avoid
clobbering the user's project `AGENTS.md`, KBD writes a **context prefix file**:

```bash
# Generated by kbd-goal-codex-setup.sh per goal
cat .codex-kbd-context.md
```

Contents:
```markdown
# KBD Goal Context

**Goal:** <description>
**Slug:** <slug>
**Active phase:** <phase>
**Stopping condition:** <condition>
**Key files:**
- SPEC.md: .kbd-orchestrator/goals/<slug>/SPEC.md
- TASKS.md: .kbd-orchestrator/goals/<slug>/TASKS.md
- STATE.md: .kbd-orchestrator/goals/<slug>/STATE.md
```

**User instruction:** Add this to your project `AGENTS.md`:
```markdown
@include .codex-kbd-context.md
```

## Goal Invocation (Per Phase)

For Creation phase, KBD invokes Codex as:
```bash
codex /goal "all tasks in TASKS.md are [x]; tests pass; lint clean"
```

Codex's Ralph Loop then:
1. Runs turns until the stopping condition is met
2. Injects `~/.codex/goals/continuation.md` (KBD's template, with slug/condition filled)
   when condition not yet met
3. Injects `~/.codex/goals/budget_limit.md` (KBD's template) when budget exhausted

## Evaluator

Codex has a built-in evaluator model that checks the stopping condition after
each turn. KBD does **not** invoke `kbd-goal-evaluator` for Codex's Creation phase.

`kbd-goal-evaluator` is used for Ideation and Specification phases (which are
always KBD-owned, not delegated).

## Routing Decision Table

| Phase | Strategy |
|---|---|
| Ideation | Always KBD (never delegated to Codex) |
| Specification | Always KBD (never delegated to Codex) |
| Creation | Delegate to `codex /goal "<stopping_condition>"` |
| Deployment | Delegate to `codex /goal "<deploy-condition>"` |

## Requirements

- Codex CLI ≥ 0.128.0 (`codex --version`)
- `goals.enabled = true` in `~/.codex/config.toml`
- Run `scripts/kbd-goal-codex-setup.sh` once per machine
