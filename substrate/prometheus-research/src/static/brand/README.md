## Regenerating PNGs

If the source SVG changes:

```bash
BRAND_DIR="substrate/prometheus-research/src/static/brand"
for variant in light dark; do
  for size in 16 32 180 512; do
    rsvg-convert -w "$size" -h "$size" \
      -o "$BRAND_DIR/primary-${variant}-${size}.png" \
      "$BRAND_DIR/primary-${variant}.svg"
  done
done
```

`rsvg-convert` is available via `brew install librsvg`. Alternatives:
`inkscape --export-type=png --export-width=$size` or a Node `sharp` script.
