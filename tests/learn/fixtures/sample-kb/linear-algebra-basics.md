# Linear Algebra Basics

## Vectors
A vector is an ordered list of numbers. In 2D space, a vector [3, 4] represents
a point or direction with x=3, y=4.

**Common misconception**: Vectors are just points. (FALSE — vectors have both
magnitude and direction; points have only position.)

## Matrices
A matrix is a rectangular array of numbers. A 2×2 matrix has 2 rows and 2 columns.
Matrix multiplication is not commutative: AB ≠ BA in general.

**Common misconception**: Matrix multiplication is commutative like regular multiplication. (FALSE)

## Linear Independence
Vectors are linearly independent if no vector can be expressed as a linear
combination of the others.

## Eigenvalues
An eigenvalue λ satisfies: Av = λv for some non-zero vector v.
